# Вход по QR-бейджу: запуск (один раз)

1. **База.** Supabase → SQL Editor → вставить содержимое `stage20.sql` → Run.
2. **Функция.** Supabase → Edge Functions → Create function, имя строго `badge-login`.
   Вставить код из `badge-login.ts` → Deploy.
   (Если есть переключатель «Verify JWT», можно оставить включённым: сайт передаёт ключ anon сам.)
3. **Сайт.** Выложить все файлы из архива на хостинг (Render/GitHub), как обычно.
4. **Бейджи.** Войти суперадмином → на панели плитка «Бейджи QR» →
   «Создать QR всем, у кого его нет» → отметить галочками → «Печать выбранных».
   Печать на A4: 9 бейджей на лист (60×90 мм), QR 46 мм, имя крупно под кодом.
5. **Вход.** На экране входа справа от кнопки «Войти» значок QR → камера → поднести бейдж.

Потерял бейдж: «Отозвать» (старый код сразу перестаёт работать) или «Новый QR».
Админам и суперадмину вход по QR отключён, у них остаётся логин и пароль.
Печатайте на матовой плёнке или ламинируйте матовой плёнкой: глянец даёт блики.
